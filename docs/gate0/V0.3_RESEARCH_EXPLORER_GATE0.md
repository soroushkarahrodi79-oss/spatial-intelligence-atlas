## 2. Diagnosis

**Visual [I].** v0.2 is rigorous, but it uses a graph form for four nodes that
have no relationships to each other. It splits one case across three modes,
is dark-only, and has no deep links and no print view. It lacks the basic unit
of an academic portal: one citable page per research item. PR #14 diagnosed
this correctly.

**Scientific [F]/[I].** Discipline is the main asset: claim ceilings, visible
negative results, and `input_kind` kept separate from `substantiation`. The
model has these gaps:

- no structured data provenance (publisher, licence, vintage, checksum);
- no *method* entity;
- uncertainty and limitation are merged into one field;
- no outcome vocabulary for `MODIFY`, `HOLD` or `MIXED`, which newer research uses;
- the DOI-backed HATI pilot is absent (only its extension appears);
- nothing detects a source becoming unreachable, as happened with CHALUS.

**Technical [F]/[I].** Four files, zero dependencies and a static Pages site
are the right base and should stay. Invariants I1–I10 are, however, checked by
hand. `DESIGN_CONTRACT.md` §9.3 forbids tests and CI, yet the repository
already ships a CI workflow. At roughly 6 research items and 30–40 records,
manual checking stops being reliable. A scheduled link check would have
caught the CHALUS 404.

**Academic [F]/[I].** The Atlas cannot be cited: it has no licence, no CFF and
no PID. `SPEC.md` §9.7 forbids a "publication list", which conflicts with the
new *Publications & Datasets* requirement. §7 reconciles the two.

## 5. Information architecture and sketch

### 5.1 Principles [P]

- **The document is the page; the graph is a secondary view.**
- Each research item is a separate unit. Every relation is **typed, has a declared class, and has a source**.
- Geography is drawn only from **public, pinned, licensed geometry**.
- The site stays static on GitHub Pages, with no runtime dependencies.

### 5.2 Routes (hash-based, citable, no server configuration) [P]

```
#/                      Overview: scientific identity, how to read, claim ceiling
#/research              Research index (fixed order, grouped by class)
#/research/<id>         Dossier
#/atlas[/<territory>]   Cartographic plates (verifiable geometry only)
#/evidence              Evidence Explorer (faceted table)
#/outputs               Publications & Datasets (PIDs only)
#/timeline              Dated milestones taken from sources
#/about                 Atlas method, licences, how to cite, governance
#/methods               later phase (v0.3.x)
#/relations             later phase (v0.4, semantic graph)
```

### 5.3 Usefulness of each component [P]

| Component | Value | Risk | Decision |
|---|---|---|---|
| Overview | high (30-second orientation) | drift into a CV or marketing page | v0.3.0; factual attribution only, no bio or photos |
| Dossiers | highest (the citable unit) | — | v0.3.0, ported from PR #14 plus the academic fields |
| Cartographic atlas | medium–high (spatial identity) | false precision; tiles mean external requests | v0.3.0, **bounded** (see below) |
| Evidence Explorer | high for reviewers | being read as a ranking | v0.3.0: table with facets for `input_kind`, `substantiation`, research item and territory; no sorting by "strength", no aggregates, no scores |
| Publications & Datasets | high (academic use) | turning into a CV | v0.3.0: only PIDs tied to a research item, with peer-review status explicit ("preprint, not peer-reviewed") |
| Timeline | medium, low cost | implying progression or maturity | v0.3.0 as a dated list, no chart |
| Methods library | medium–high | extraction workload at Gate 2 | v0.3.x |
| Semantic graph | low at current size | implying integration | v0.4, only once at least two sourced relation types exist; deterministic SVG reusing v0.2 code |
| WebGL / 3D globe | negative | PR #10 precedent | **Rejected** |
| Light theme and print | high for academic use (PDF of a dossier) | contrast | v0.3.0 |
| Spanish / English | medium | maintenance cost | later |

**Cartographic atlas, bounded.** Plates are SVG, pre-projected and simplified
offline, with no basemap, tiles or Leaflet. Each plate states its source,
licence, CRS and simplification tolerance, and says "not for measurement".

Geometry available [F]:

- the official barrio 113 polygon (`madrid_admin.geojson` in the Lens repo);
- the OAPN boundary of PNSG (`oapn_limite_pn.geojson` in the SNTO repo; licence checked at Gate 2);
- the frozen HATI routes, with hashes (`route_freeze_hashes.json`).

Western Mazandaran gets no plate (D1).

### 5.5 Technical architecture [P]

- **Page:** one `index.html` with a hash router. JavaScript as **native ES modules** in `js/` (no bundler). One stylesheet, with `@media print` and light/dark themes.
- **Data:** `data/atlas.json` (schema 0.3.0) and `data/geometry/*.json` (simplified geometry with provenance). The only runtime requests are same-origin.
- **Development only, never loaded by the page:**
  - `tools/validate_atlas.py` (standard library only), checking invariants I1–I14;
  - CI workflows: validation on every PR, plus a scheduled source link check.
- **Budget:** under 300 KB transferred excluding geometry; geometry under 150 KB. No web fonts, CDN, telemetry, runtime AI, backend or `localStorage`.

## 6. Academic model (schema 0.3.0, minimal) [P]

```text
research       id, title, class(documented_research|research_platform|instrument|
               proposal|experiment|archived_artifact), research_question|null,
               lifecycle_status, version{ref, kind:tag|commit|doi},
               license{code, data, text}  (each: spdx|custom|none + source_id),
               reproducibility{level: rerunnable|inspectable|documented_only|none,
               instructions_source_id}, identifier_ids[], reviewed_at, source_ids[]
territory      id, label, basis, geometry_id|null, source_ids[]
geometry       id, source_id, publisher, license, crs, simplification_m, sha256
evidence       id, input_kind (nature), substantiation (documentary support),
               statement, limitation,
               provenance{publisher, dataset_ref, license, retrieved_at, checksum}|null,
               source_ids[]
method         id, label, description, source_ids[]                   (v0.3.x)
finding        id, statement, uncertainty|null (only when the source quantifies
               or describes it), source_ids[]
outcome        id, verdict_label (verbatim from source: "MODIFY", "ABSTAIN"…),
               outcome_type(bounded_finding|abstain|insufficient_evidence|no_go|
               functional_test|conditional|hold|mixed)   — categorical, not ordinal
               statement, claim_ceiling, limitations[], source_ids[], reviewed_at
identifier     id, scheme:doi, value, scope:version|concept,
               output_type:preprint|dataset|software|article,
               peer_review:none|under_review|peer_reviewed, license, date, source_id
source         id, label, kind, url, pinned_ref, accessed_at,
               access:public|restricted, last_checked_at, last_http_status
relationship   id, type, class(structural|conceptual|technical), source, target, source_ids[]
               structural: situated_in, documents, reports, has_output, has_finding
               conceptual: uses_method                                  (v0.3.x)
               technical:  consumes_artifacts_of, supports              (source mandatory)
```

**Where each required concept lives:**

| Concept | Field |
|---|---|
| Research question | `research_question` |
| Territory | `territory` + `geometry` |
| Data provenance | `evidence.provenance` |
| Methodology | `method` / `uses_method` |
| Evidence | `evidence` |
| Findings | `finding` |
| Uncertainty | `finding.uncertainty` |
| Limitations | `evidence.limitation` + `outcome.limitations` |
| Claim ceiling | `outcome.claim_ceiling` |
| Sources | `source` |
| Publication identifiers | `identifier` |
| Version | `research.version` |
| Licence | `research.license` (code, data and text kept separate) |
| Reproducibility | `research.reproducibility` |

**Mandatory separation:**

- `input_kind` (the nature of the evidence) and `substantiation` (how well documentation supports it) stay two axes and are never combined.
- `outcome_type` is not ordinal.
- `verdict_label` is quoted verbatim and never reinterpreted.

**New invariants:**

- **I11:** every public claim rests on at least one `access: public` source.
- **I12:** every drawn geometry resolves to a `geometry` object with a licence and a hash.
- **I13:** every relation between research items declares its `class` and a source. The `technical` class requires a source documenting the dependency.
- **I14:** `verdict_label` matches the pinned source verbatim.

**Academic metadata of the Atlas (D4).** Code and `data/atlas.json`
data/text get separate licences, chosen by the maintainer before Gate 4.
After that choice:

- `CITATION.cff` is added;
- the GitHub→Zenodo integration is enabled, only with explicit authorisation;
- the first DOI is minted at `v0.3.0`; there are **no** retroactive DOIs for `v0.1.x` or `v0.2.x` (`PROJECT_STATUS.md` §9);
- the version and concept DOIs are recorded in `PROJECT_STATUS.md`.

Material quoted from sources with their own licence (SNTO: academic use) is
limited to paraphrase or short quotation.

## 7. Required changes to SPEC and DESIGN_CONTRACT [P]
